# VLA-to-NPU: Optimized Vision Language Action Model on AMD Phoenix NPU

This repository contains kernel implementations and optimized inference pipelines for Vision Language Action (VLA) models on AMD Phoenix NPU, built with [Allo](https://github.com/heterogeneous-computing-lab/allo) and optimized with Claude.

## Quick Start

### Run End-to-End VLA (Optimized C++ Pipeline)

```bash
cd vla
python3 vla_standalone.py
```

**Output (~6 seconds):**
```
Running standalone VLA pipeline (no df.build())...

== Timings (standalone, no rebuild) ==
Preprocessing           : 0.18 s
Vision encoder (12L)    : 2.51 s
Connector               : 0.18 s
Joint transformer (12L) : 3.21 s
Postprocessing          : 0.08 s
Total                   : 6.16 s
Output shape: (32, 32)
```

### Run a VLA Component (Vision Encoder)

To see how individual components work with Allo:

```bash
cd vla
python3 vision_block_bf16.py
```

This demonstrates the Python Allo implementation before C++ optimization.

### Run Individual Kernel Tests

```bash
cd kernel_testing/silu
python test_silu_bf16_new.py
```

## Architecture

### Three Implementation Levels

| Level | File | Speed | Use Case |
|-------|------|-------|----------|
| **Optimized (C++)** | `vla_standalone.py` | **6.16s** | End-to-end inference |
| **Allo (Python)** | `vla.py` or component files | ~23s | Educational, component development |
| **Individual kernels** | `kernel_testing/*` | Varies | Kernel-level optimization |

### Why vla_standalone.py is Fast

- **vla.py** (Allo): Generates a separate executable for each kernel call → overhead from 20+ dispatch calls
- **vla_standalone.py** (Claude-optimized): Calls pre-built `unified.prj` binaries that combine multiple kernels → single dispatch per component

See [NPU_PROGRAMMING.md](NPU_PROGRAMMING.md) for how unified.prj is generated.

## Model Configuration

**Default:** 12-layer ViT + 12-layer text encoder + 16-layer action expert

To adjust, edit `vla/vla_standalone.py`:

```python
VIT_NUM_LAYERS = 12        # Change to smaller for faster iteration
LLAMA_NUM_LAYERS = 12      # Text encoder depth
SKIP = 2                   # Action expert skip
```

---

## Key Optimizations

1. **Unified Binaries** — Claude-generated `.unified.prj/` combines kernels to eliminate per-call overhead
2. **Flash Attention** — 3-pass attention → 1 kernel (408 → 192 dispatches/layer)
3. **Vectorized GELU** — Padé approximation with 15.5× speedup
4. **Multi-Layer Binary** — 12 transformer layers in single process (no context switching)
