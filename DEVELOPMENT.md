# Development Guide: Updating Code

## Which VLA Script to Run?

```bash
cd vla
python3 vla_standalone.py  # ✅ Use this for end-to-end
```

| Script | Type | Speed | Purpose |
|--------|------|-------|---------|
| **vla_standalone.py** | C++ (optimized) | **6.16s** | Production inference |
| vla.py | Allo (Python) | ~23s | Educational reference |
| vla_cpp.py | Helper module | — | Internal (imported by vla_standalone.py) |

See [NPU_PROGRAMMING.md](NPU_PROGRAMMING.md) for why `vla_standalone.py` is fast.

---

## File Types

### Files You Write (Source of Truth)

```
cc/bf16/my_kernel.cc              ← C++ kernel with AIE API
cc/bf16_vla/my_kernel.cc          ← VLA-specific kernels
vla/my_component_bf16.py          ← Allo code mapping kernels to tiles
kernel_testing/my_kernel/test_*.py ← Test scripts
```

### Files Generated by Allo (Compiled Artifacts)

```
*.prj/build/final.xclbin   ← Compiled binary (except unified.prj)
*.prj/build/insts.txt      ← Instructions
top.mlir                   ← MLIR intermediate representation
CMakeLists.txt             ← Build configuration
```

### Files Generated by Claude (Unified.prj Only)

```
unified.prj/test.cpp       ← C++ that combines multiple kernels
unified.prj/build/         ← Compiled unified executable
```

## Update Workflows

### Scenario 1: Update a Kernel

**Example: Optimize SiLU**

```bash
# Step 1: Edit kernel source
vim cc/bf16_vla/silu_128_bf16.cc

# Step 2: Rebuild with Allo (if exists)
cd vla/text_encoder_bf16
python build_silu.py  # Generates silu.prj/build/final.xclbin

# Step 3: Test the kernel
cd ../../kernel_testing/silu
python test_silu_bf16_new.py  # Should PASS

# Step 4: If component affected, regenerate unified.prj
# Use Claude prompt to update unified.prj/test.cpp to include new kernel

# Step 5: Test end-to-end
cd ../../vla
python3 vla_standalone.py

# Step 6: Commit source files only
git add cc/bf16_vla/silu_128_bf16.cc kernel_testing/silu/test_silu_bf16_new.py
git commit -m "Optimize SiLU kernel: improve vectorization"
```

### Scenario 2: Update Allo Code

**Example: Modify RMS Norm tiling**

```bash
# Step 1: Edit Allo code
vim vla/text_encoder_bf16/rms_norm.py

# Step 2: Rebuild
python vla/text_encoder_bf16/rms_norm.py
# Generates: rms_norm.prj/build/final.xclbin

# Step 3: Test component
python vla/text_encoder_bf16.py

# Step 4: Test end-to-end
cd vla
python3 vla_standalone.py

# Step 5: Commit
git add vla/text_encoder_bf16/rms_norm.py
git commit -m "Improve RMS Norm tiling strategy"
```

### Scenario 3: Update Python Logic

**Example: Fix VLA component flow**

```bash
# Step 1: Edit Python code
vim vla/vision_block_bf16.py

# Step 2: Test component
python vla/vision_block_bf16.py

# Step 3: Test end-to-end
python vla/vla_standalone.py

# Step 4: Commit
git add vla/vision_block_bf16.py
git commit -m "Fix vision block attention logic"
```

## .gitignore Policy

**DO NOT COMMIT:**
```
*.prj/build/               ← Allo-generated binaries (rebuilt locally)
*.xclbin                   ← Compiled
insts.txt                  ← Allo-generated
*.mlir                     ← Intermediate representation
test_results*.log          ← Test output
```

**DO COMMIT:**
```
cc/bf16/*.cc               ← Kernel sources
vla/*.py                   ← Model code
kernel_testing/*/*.py      ← Tests
unified.prj/test.cpp       ← Claude-generated (if not tracked, regenerate)
```
